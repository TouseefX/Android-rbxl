# Roblox Builder fonts

These font files are used only to render Roblox experience UI previews accurately.
They were retrieved from the Roblox Builder font collection at:

https://github.com/Shuiux/Roblox-Builder-Fonts

The repository's license is preserved in `LICENSE`. Builder fonts may also be
subject to Roblox's Builder Font License and should only be used for Roblox-related
content. The editor does not expose these files as a general-purpose font package.
